- **Goal**: A class of automata that accepts the context-free languages
	- We need some form of infinite memory to accept languages like $$\{a^{n}b^{n}\mid n\geq 0\}$$
- A pushdown automaton has a [[Stack]] of unlimited size
	- We have input alphabet $\Sigma$ and stack alphabet $\Gamma$
	- stacks are ordered in words with top-element on the left
	- a transition reads the topmost element of the stack $$\delta:Q \times (\Sigma\cup \{\lambda\}) \times {\color{#58F}\Gamma} \to 2^{Q \times {\color{#58F}\Gamma^{*}}}$$ and exchanges it with zero or more new elements
	- The nondeterministic choice $\delta(q,\alpha, b)$ must always be **finite**!

> [!definition] NPDA
> A **nondeterministic pushdown automaton** is a tuple $$M=(Q,\Sigma,\Gamma,\delta,q_{0},z,F)$$
> - a finite set $Q$ of states
> - a finite input alphabet $\Sigma$
> - a finite stack alphabet ${\color{#F08}\Gamma}$
> - a transition function $${\color{#F08}\delta : Q\times (\Sigma \; \cup \{\lambda\}) \times \Gamma \to 2^{Q \times \Gamma^{*}}}$$ where $\delta(q,\alpha,b)$ is always finite
> - a starting state $q_{0}\in Q$
> - a stack starting symbol ${\color{#F08}z\in \Gamma}$
> - a set $F\subseteq Q$ of final states

The transition function $\delta$ takes as arguments 
- the current state $q$, 
- the next input symbol $a\in \Sigma$ or $a=\lambda$, and 
- the topmost stack symbols $b\in \Gamma$, 

and the value $\delta(q,a,b)\subseteq Q \times \Gamma^{*}$ is a set of pairs $(q',w)$ where
- $q'$ is next state, and
- $w \in \Gamma^{*}$ is a word with letters from the stack alphabet $\Gamma$ 
---

- If $(q',v)\in \delta(q,\alpha,b)$, automaton can transition from state $q$ with input $\alpha w$ and stack $bu$ to $q'$ with input $w$ and stack $vu$ $$(q,\alpha w,bu)\vdash (q', w, vu)$$
- The language generated by NPDA $M=(Q,\Sigma, \Gamma, \delta, q_{0},z,F)$ is $$L(M)=\{w\in \Sigma^{*} \mid (q_{0},w,z)\vdash^{*} (q', \lambda, u) \text{ where } q' \in F\}$$
	- Am empty stack language (accepted only when stack is empty) is $$L_{\lambda}(M)=\{w\in \Sigma^{*} \mid (q_{0},w,z) \vdash^{*} (q', \lambda, \lambda)\}$$
- The transition graph for a NPDA contains $$\text{for every } \quad (q',v)\in \delta(q,\alpha, b) \quad \text{an arrow} \quad q \overset{\alpha [b/v]}{\longrightarrow} q'$$

- Every NPDA $M$ can be transformed into NPDA $N$ such that
	- it has a **single final state** $F=\{q_{f}\}$
	- **final state is reached iff the stack is empty**
	- $L(M)=L(N)=L_{\lambda}(N)$

### Construction Final States to acceptance with Empty Stack
We add fresh states $\{\widehat{q_{0}}, q_{e}, q_{f}\}$ to $Q$ and stack element $\hat z$ to $\Gamma$.
- Add a transition $\widehat {q_{0}} \xrightarrow{\lambda[z/z\hat z]}q_{0}$ 
- Add transitions $q\xrightarrow{\lambda [s/s ]} q_{e}$ for every $q\in F, s\in \Gamma$
- Add transitions $q_{e}\xrightarrow{\lambda [s/\lambda]} q_{e}$ for every $s\in \Gamma\setminus \{\hat z\}$
- Add transition $q_{e}\xrightarrow{\lambda [\hat z/\lambda]} q_{f}$
- Define $\widehat{q_{0}}$ as starting state and $F=\{q_{f}\}$

## Context-free languages and NPDA's
> [!info] THEOREM
> A language $L$ is [[Context-free Languages|context-free]] <==> there exists an NPDA $M$ with $L(M)=L$

### Construction From Context-free grammars to NPDA's
Let $G=(V,T,S,P)$ be a context-free grammar. 
**Idea**: simulate leftmost derivation on the stack
We construct an NPDA $M=(Q,\Sigma, \Gamma, \delta, q_{0}, z, F)$ as follows:
$$\begin{align}
Q & =\{q_{0},q_{1},q_{2}\} && \Sigma = T \\
F & = \{q_{2}\} && \Gamma = V \cup T \cup \{z\}
\end{align}$$
We add transitions simulating a leftmost derivation:
$$\begin{align}
& q_{0} \xrightarrow{\lambda [z/Sz]} q_{1} \\
& q_{1} \xrightarrow{\lambda [A/x]} q_{1} \text{for every } A\to x\in P\\
& q_{1} \xrightarrow{a [a/\lambda]} q_{1} \text{for every } x\in T\\
& q_{1} \xrightarrow{\lambda [z/\lambda]} q_{2} \\
\end{align}$$
Then $L(M)=L(G)$

### From NPDA's to Context-free grammars
Let $M=(Q,\Sigma,\Gamma,\delta,q_{0},z,F)$ be an NPDA. Transform $M$ s.t.
**Assumption**: $F=\{q_{f}\}$ and $q_{f}$ reachable only with empty stack.
We define a context-free grammar $(V,T,S,P)$ as follows: $$T = \Sigma \qquad V=\{(q\,b\,q') \mid q,q'\in Q,b \in \Gamma\} \qquad S=(q_{0}\, z\, q_{f})$$
**Intuition**: $(q\,b\,q') \Rightarrow^{+} w \iff (q,w,b)\vdash^{+} (q', \lambda, \lambda)$
The set $P$ contains the following rules:
- If $q \xrightarrow{\alpha[b/\lambda]} q'$, then $(q\,b\,q')\to \alpha$ in $P$
- If $q \xrightarrow{\alpha[b/c_{1}\cdots c_{n}]} q'$ with $n\geq 1$, then $(q\,b\,r_{n})\to \alpha(q'\,c_{1}\,r_{1})(r_{1}\,c_{2}\,r_{2})\cdots (r_{n-1}\, c_{n}\, r_{n})$ in $P$ for **all** $r_{1},...,r_{n}\in Q$

Then we have $L(G)=L(M)$

# Deterministic Pushdown Automata
- A deterministic pushdown automaton (DPDA) is an NPDA such that
	- $\delta(q,\alpha, b)$ contains at most one element
	- If $\delta(q,\lambda, b)\neq \emptyset$, then $\delta(q,a,b)=\emptyset$ for every $a\in \Sigma$
- A language $L$ is deterministic context-free if there exists a DPDA $M$ with $L(M)=L$

> [!info] THEOREM
> It is *decidable* if two DPDA's generate the same language
