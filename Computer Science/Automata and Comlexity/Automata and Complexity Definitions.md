# Regular Language
## DFA
> [!definition] DFAs
> A **deterministic finite automaton** consists of: 
> - a finite set $Q$ of **states**
> - a finite **input alphabet** $\Sigma$
> - a **transition function** $\delta : Q\times \Sigma\to Q$
> - a **starting state** $q_{0}\in Q$
> - a set $F\subseteq Q$ of **final states**

- **Completeness**: An automaton is complete if every state $q$ has an outgoing transition for every input letter $a\in \Sigma$
- **Determinism**: An automaton is _deterministic_ if for every input word, there is a unique path (sequence of transitions) through the automaton when reading the word. In particular, there exists no state $q$ having _two outgoing transitions with the same label_ $a\in \Sigma$.
- The language accepted by DFA $M=(Q,\Sigma, \delta, q_{0}, F)$ is 
  $$\begin{align*} L(M) 
  &= \{w\in \Sigma^{*}\mid \text{$M$ has an accepting run for $w$}\} \\
  &= \{w\in \Sigma^{*}\mid (q_{0},w) \vdash^{*} (q,\lambda) \text{ with } q\in F\} \\ 
  &= \{w\in \Sigma^{*}\mid q_{0} \overset{w}{\twoheadrightarrow} q \text{ with } q\in F\} \end{align*}$$
## NFA

> [!definition] NFAs
> A **nondeterministic finite automaton** consists of: 
> - a finite set $Q$ of states
> - a finite input alphabet $\Sigma$
> - a transition function $\delta : Q\times (\Sigma \;{\color{#F08} \cup \{\lambda\}})\to {\color{#F08}2^Q}$
> - a set of starting states ${\color{#F08}S\subseteq Q}$
> - a set $F\subseteq Q$ of final states

- The language accepted by NFA $M=(Q,\Sigma, \delta, S, F)$ is $$\begin{align*}L(M) &= \{w\in \Sigma^{*}\mid (q_{0},w) \vdash^{*} (q,\lambda) \text{ with } q_{0} \in S, q\in F\} \\ &= \{w\in \Sigma^{*}\mid q_{0} \overset{w}{\twoheadrightarrow} q \text{ with }q_{0}\in S, q\in F\} \end{align*}$$
## Grammar
- A **grammar** defines a **language**.

> [!definition] Grammar
> A **grammar** $G=(V,T,S,P)$ consists of:
> - finite set $V$ of **non-terminals** (or **variables**)
> - finite set $T$ of **terminals**
> - a **start symbol** $S\in V$
> - finite set $P$ of **production rules** $x\to y$ where
> 	- $x \in (V\cup T)^{+}$ containing at least one symbol from $V$
> 	- $y \in (V\cup T)^{*}$

- The [[Finite Automata#Regular Languages|language]] generated by a grammar $G=(V,T,S,P)$ is $$L(G)=\{w\in T^{*}\mid S\Rightarrow^{*}w\}$$
	- the words contain only terminal symbols
	- the words can be derived from the start symbol
- A grammar is **context-free** if the left-hand side of all rules is a variable
- A language is **context-free** if it is generated by a context-free grammar
- A grammar $G=(V,T,S,P)$ is **right linear** if all production rules are of the form $$A \to uB \quad \text{or} \quad A\to u$$ with $A,B \in V$ and $u\in T^{*}$. Moreover $G$ is **strictly right linear** if $|u|\leq 1$ (i.e. $u\in (T\cup \{\lambda\}$)
## Regular Expression
> [!info] Regular Expression
> We define the regular expressions over an alphabet $\Sigma$:
> - $\emptyset$ is a regular expression
> - $\lambda$ is a regular expression
> - $a$ is a regular expression for every $a \in \Sigma$
> - $r_{1}+r_{2}$ is a regular expression for all regular expr. $r_{1}$ and $r_{2}$
> - $r_{1}\cdot r_{2}$ is a regular expression for all regular expr. $r_{1}$ and $r_{2}$
> - $r^{*}$ is a regular expression for all regular expressions $r$

Every **regular expression** $r$ defines a **language** $L(r)$:
- $L(\phi)=\phi$
- $L(\lambda)=\lambda$
- $L(a)=\{a\} \text{ for some } a \in \Sigma$
- $L(r_{1}+r_{2})=L(r_{1})\cup L(r_{2})$
- $L(r_{1}\cdot r_{2})=L(r_{1})L(r_{2})$
- $L(r^{*})=L(r)^{*}$

## Pumping Lemma
A language $L$ has the **pumping property** if there **exists** $m > 0$ such that **every** $w \in L$ with $\left|\right. w \left|\right. \geq m$ can be written in the form
$$
w = x y z
$$
with $\left|\right. x y \left|\right. \leq m$ and $\left|\right. y \left|\right. \geq 1$, and $x y^{i} z \in L$ for every $i \geq 0$.

> [!important] Every regular language has the pumping property.

# Context-free Language 
### Context-Free Grammars

A grammar $G = \left(\right. V , T , S , P \left.\right)$ is called **context-free** if all production rules are of the form
$$ A \rightarrow u $$
where $A \in V$ and $u \in \left( V \cup T \right)^{*}$.

A language $L$ is **context-free** if there exists a context-free grammar $G$ such that $L \left(\right. G \left.\right) = L$.
