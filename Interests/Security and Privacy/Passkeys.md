Using password authentication on websites brings two downsides, mainly:
- Passwords are hard to remember
- Passwords can be brute-forced
- Password login is susceptible to [[phishing]], given that the user doesn't use/uses a weak form of [[2FA]]

Passkeys were invented to combat these issues. Passkeys use a form of [[SP Cryptography#Asymmetric Cryptography|public key cryptography]]
